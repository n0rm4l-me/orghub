# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please use one of the following methods:

- **GitHub private advisory**: open a private security advisory at the repository's Security tab (do not open a public issue).
- **Email**: if configured, email the address listed in your instance's site settings.

Please include a description of the issue, steps to reproduce, and the potential impact. We aim to respond within 5 business days.

Do not disclose the vulnerability publicly until a fix has been released.

## Supported Versions

Security fixes are applied to the latest release only. We recommend keeping your OrgHub instance up to date.
